# Acid 学猫叫（固件试验，分支 acid-cat）

照视频「如何用 Acid 学猫叫？」（function-sounds/video/acid-cat.html）的做法，给 FN ACID 加了两样东西：

- **动物叫声插入**：演奏时随手按出一声叫。
- **MEOW 预设旋律**：用 303 自己的方式录好的一声喵。

原理和视频一样：

- 共振低通的尖峰就是一个能移动的共振峰（嘴）。CUTOFF 先开后合 = 嘴张开再合上。
- 音高用“步 + 滑音”拼出先升后降的弧线。
- 嘴张得最大时，音高也最高。

## 1. 动物叫声：按住 FX + 黑键

FX 层原来只用了 16 个白键，现在 11 个黑键用来放叫声。

| 黑键 | 琴键 | 叫声 | 音区 |
|---|---|---|---|
| 1–5 | F#3 G#3 A#3 C#4 D#4 | MEOW · MEW · MOO · QUACK · WOOF | 低（“bass 喵”） |
| 6–10 | F#4 G#4 A#4 C#5 D#5 | MEOW · MEW · MOO · QUACK · WOOF | 动物自己的音区 |
| 11 | F#5 | LONG（一整小节的长喵） | 原音区 |

- 按一下 = 叫一声。播放中会对齐到下一个 16 分音符才开始；停着时立刻叫，可以先单独试听。
- 叫的时候，ACID 这一轨由叫声接管，叫完自动回到原来的旋律。连着按，后一声会接替前一声，可以按出“喵喵喵”。
- 叫声有自己的 CUTOFF 曲线、RESO、包络和波形，不受旋钮影响。CUTOFF 用的是固定的 Hz，不跟音高走，所以低音区的喵“嘴型”还在。
- 音高都在根音的自然小调里（根音 A 时是 A 小调）。改了根音或 TRANSPOSE，叫声会跟着走。
- 把 ACID 静音（GLO + 白键 1）以后，叫声照样会响。这样可以只留鼓，单独插叫声。
- 屏幕上按着 FX 时，黑键上写着叫声的名字，正在叫的那个键是黑的。

每声叫的内容（根音 A，120 BPM；数字照视频的配方）：

| 叫声 | 音 | CUTOFF | 其他 |
|---|---|---|---|
| MEOW | C E E D C A，16 分音符，前 5 步滑音，E 上有重音（0.75 秒） | 520 → 2500 → 2000 → 900 → 600 Hz | RESO 0.84，没有包络 |
| MEW | C E C（短喵，3 步） | 600 → 2400 → 900 → 600 Hz | 同上 |
| MOO | C D（停住）C A，12 步（1.5 秒），低一个八度 | 180 → 330 → 900 → 650 → 240 Hz（m → oo） | RESO 0.72 |
| QUACK | D C B A，每个音之间空一步 | 700 Hz + 包络（19 个半音，衰减 100 ms） | 方波，RESO 0.9，第 1、4 个音有重音 |
| WOOF | 32 分音符：D→B 一声，三声排成“汪汪…汪” | 450 → 380 Hz + 包络（26 个半音，衰减 80 ms） | 锯齿 + 方波，RESO 0.55，重音 |
| LONG | C E（停 6 步）D C A，16 步 | 520 → 2500 → 2350 → 1500 → 800 → 520 Hz | RESO 0.86 |

## 2. MEOW 预设旋律：按住 HOME + 白键 8

- 前半小节是 FILM 那条线。后半小节是低一个八度的喵：C3 E3 E3 D3 C3 A2，带滑音。
- 嘴型录在**旋钮动作**里：CUTOFF 先开后合，RESO 0.84，ENV 0。这就是一台 303 加一只拧旋钮的手能做到的喵。
- 前半小节没有录旋钮动作，所以 CUTOFF 等旋钮还是照常控制贝斯。
- 可以照常编辑、存进 U1–U6。按 REC + 白键 5 会把录的嘴型清掉。
- 限制：旋钮动作里 CUTOFF 开到头约 2 kHz，比视频里的 2.5 kHz 低一点。想更亮，就用 FX + 黑键的 MEOW。

## 3. 怎么试

1. 按 PLAY 放任意一条旋律（比如 HOME + 白键 10 FILM）。
2. 按住 FX，在重音的位置按黑键 6（MEOW）。
3. 再试黑键 1（低音区的喵）、黑键 11（长喵）。
4. Drop 的玩法：按黑键 1 → 6 → 11，叫声一个八度一个八度往上爬，和视频的 Drop 一样。
5. 按住 HOME 按白键 8，听 303 自己录好的喵。

## 4. 离线检查（电脑上模拟，没有上机）

- 主机版（tests/host.c）脚本：
  - `tests/scripts/acid-cat.txt`：停着，单独叫，关掉延时和混响；
  - `tests/scripts/acid-cat-live.txt`：MEOW 预设旋律 + 播放中插入叫声。
- 测量：`python tests/acid-cat-measure.py build/host/cat.wav`，加 `live` 测第二个脚本。
  - 音高：每 10 ms 做一次自相关，和设计的音高曲线比（含 22 ms 的滑音）。
  - 嘴型：先扣掉锯齿波 1/n 的斜率，找最响的那根谐波，和设计的 CUTOFF 曲线比。做法和 acid-animals 原型相同。

| 叫声 | 音高误差中位（音分） | ±50 音分内 | 最响谐波 vs CUTOFF：相关 / 中位差（八度） |
|---|---|---|---|
| MEOW | 3.1 | 97% | 0.96 / 0.17 |
| MEW | 11.4 | 97% | 0.82 / 0.18 |
| MOO | 7.7 | 98% | 0.97 / 0.21 |
| QUACK | 8.1 | 100% | 0.84 / 0.12 |
| WOOF | 11.5 | 100% | 0.89 / 0.47 |
| LONG | 1.2 | 98% | 0.98 / 0.13 |
| 低音区 MEOW / MEW / MOO / QUACK / WOOF | 7.3 / 8.0 / 7.4 / 7.8 / 11.2 | 94–100% | 0.85 / 0.99 / 0.99 / 0.95 / 0.95；中位差 0.06–0.41 |
| MEOW 预设旋律（第 1–3 小节） | 5.4–7.5 | 97–99% | 0.99–1.00 / 0.12 |

- 对齐：播放中 9.030 s 按 FX+MEOW，下一个 16 分音符是 9.125 s，测到叫声从这里开始；10.510 s 按 LONG，从 10.625 s 开始。
- 叫完以后，原来的旋律接着放。
- 没有 NaN，峰值 0.68–0.72。
- 设备版 `./build.sh` 全部检查通过：
  - 程序 220272 B / 581564；
  - RAM 34576 B / 98304；
  - 没有软件双精度；
  - .ram_text 没有函数调用。
- WOOF 的中位差大（0.4 八度），因为每声只有 62 ms，包络冲得很快，测出来的峰比设计的低。音高是对的。

## 5. 听的时候注意什么

- **MEOW**：E 那一步应该是最亮、最“张嘴”的，结尾落回 A 时声音变闷。如果听着像“哇”不像“喵”，多半是嘴张开得太快（CUTOFF 曲线第二个点可以往后挪）。
- **低音区 MEOW**：音低了两个八度，“嘴型”应该还在，这就是“bass 喵”。
- **MOO**：开头很闷（m），中间慢慢打开（oo），然后合上。
- **QUACK**：方波 + 高共振的鼻音，四声往下走。这是“303 原机就能做”最好的一只。
- **WOOF**：只能算半只狗。真的狗叫有沙哑和气声，要靠噪声，303 没有；这里只有重音 + 快包络的“冲”。听着不像就别用，告诉我是起音不对还是音高不对。
- 每个叫声的音量和重音是按 ACID 的 LEVEL 和 ACCENT 走的。

## 6. 做不到的（没有放进去）

- **羊**：要颤音（LFO），叫声里没做。
- **乌鸦**：要噪声和失真。
- **海鸥、小猫**：音区和 CUTOFF 都太高，已经不像 303 了。
- **i 这个元音**：只有一个共振峰，说不出 i（要一低一高两个峰）。
