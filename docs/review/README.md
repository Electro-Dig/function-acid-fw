# FN ACID 对照评审总结（2026-10-25，0.50）

对照对象：SLOOP 2.7.1（Felucca 底座）、JIANT 0.9.12、X0X（含第二核心的版本）。逐条细节和 file:line 引用见同目录 `sloop.md`、`jiant.md`、`x0x.md`。

## 一句话

FN ACID 的 303（梯形滤波、accent / slide / tie、两台 303、曲线运算）在这几个固件里是最专精的，**声音这一块领先**。差距在工程底座：

- 音频渲染的结构；
- 代码在 flash 里的位置；
- 屏幕和按键、MIDI 共用一个忙碌的主循环；
- 存储的安全性；
- 过载保护。

## 已经实测到的

- 0.47 的机上剖析（DEEP）：KEYS 38%、鼓 11%、其余声部 10%、回声 + 混响 7%、control 1%，平均 69%。
- 0.48 把 PAD / DRONE 改成查表、半速以后，主机上 DEEP 的计算量减了 45%。机上的新数字还没测。
- 主机上，0.40 和 0.46 的纯计算量只差 3%。机上的负载却从 15–20% 涨到了 40%，说明代码布局和取指的影响很大。JIANT 0.9.10 也遇到过同一现象：只加了 6 KB 界面代码，负载就到 94%。

## 差距与建议（按"收益 / 风险"排）

### 第一批：几小时，几乎零风险

| # | 改什么 | 为什么 | 出处 |
|---|---|---|---|
| 1 | 音频半缓冲**先确认再渲染** | 现在渲染完才确认，接近满载时会吞掉一块、重播旧音频 | JIANT 0.8.9 修过同一个 bug |
| 2 | 每块的 `fpu_sum` 自检改成很久一次 | 0.34 的检查已经得到结论 | 三家都没有 |
| 3 | 去掉每个采样里的硬件除法（`u3 / 3` 两次、`/ 100` 一次），改成乘法和移位 | `-Os` 下这些是真的除法指令 | X0X 报告 |
| 4 | 回声、混响在没有输入、延迟线也空时整块跳过 | 现在只要开着就每个采样都算 | X0X、JIANT |
| 5 | CPU 读数扣掉按键 / USB 中断的时间，加"丢块计数" | 现在的数偏高，过载时也不知道丢没丢 | SLOOP、JIANT |
| 6 | MIDI 输出在音频中断里直接写进 USB 队列 | 现在要经主循环转发，被屏幕传输卡住，时钟抖动 30–50 ms | X0X |
| 7 | 屏幕 SPI 从 12 MHz 提速 | 主循环每帧要干等 24–54 ms，按键、MIDI 都跟着慢 | X0X、fm1-base-amb 都用 60 MHz |

### 第二批：1–2 天，低到中风险

| # | 改什么 | 为什么 |
|---|---|---|
| 8 | 链接时把音频用到的函数和表排在 flash 最前面 | 界面以后怎么改都不会再挤动声音的代码 |
| 9 | 存储改 A/B 两个扇区轮流写；擦除前清空音频缓冲；播放中只记在内存里，停下后再写 | 现在播放中存档会"嗡"一下，写到一半断电会丢全部 6 个槽 |
| 10 | 负载保护：超过阈值时 KEYS 不再加新声部、先砍很轻的尾音；偷声部时淡出几毫秒 | 现在过载就直接爆音；偷声部会咔哒一声 |
| 11 | 接收 MIDI 音符输入（按通道弹各条轨） | 现在外接键盘弹不了；X0X 支持 USB 和 TRS 输入 |
| 12 | 按键、旋钮的扫描移到定时中断里 | 不再受屏幕刷新影响，手感更稳 |

### 第三批：2–4 天，要实机多测

| # | 改什么 | 为什么 |
|---|---|---|
| 13 | KEYS 和其他声部改成"按声部、按块"渲染，控制量每块算一次，FM 改整数相位 | 结构上最大的浪费；也是第 15 条的前提 |
| 14 | 最热的音频代码搬进片内 RAM（要把代码区移到 pool 顶部，才能调用 flash 里的函数） | 根治取指慢；JIANT 放了 22.8 KB |
| 15 | 第二个核心先跑 909 / 808 | 最大的一刀：X0X 实测 83% → 53%。但有的机器第二核心会读错内存，要抬供电电压、崩溃后退回单核，需要多台机器测试 |
| 16 | 320 MHz 档（flash 控制器 80 MHz） | JIANT 称约省 11%；要确认 USB、OTA、救援模式都正常 |

## 声音和玩法（围绕 acid）

- **母线响度保持器 + 带补偿的 CLIP**：acid 的 RES 和 accent 一拧就差 6–10 dB，现场音量会忽大忽小。
- **DJ FILTER 单旋钮**：左低通、右高通，居中完全旁路，不耗 CPU。
- **punch-in 量化到下一个 16 分音符，并能录进 lane**：让我们最有特色的「对曲线做运算」可以编进曲子里。
- **MUTATE ORBIT**：一条 303 线围绕原线每几小节变一点，可以退回原样；我们已有 `mutate_line`。
- **UNDO 一步、FX LATCH、旋钮加速**：骰子类功能有了撤销，用户才敢按。
- **303 的 A/B MORPH**：一个旋钮扫过两套音色，可以录进旋钮动作。
- ZOO 可以借 JIANT ANIMAL 的 PULSE（蟋蟀、蝉）和 CMOS（鸟机）源，便宜又像。

## 不建议跟的

- X0X 的 303：2 倍过采样加 float，比我们贵得多。只借它反馈路径里的高通、参数插值这类几乎免费的细节。
- JIANT 的 "ACID"：只是一个 2 极 SVF 预置。
