FN ACID

函数 Acid · M-VAVE FM-1 的自制固件 · 0.39 测试版Function Acid · a custom firmware for the M-VAVE FM-1 · 0.39 test

一台 303 式的 acid 机器，每条轨都是一条函数曲线：横轴是时间，纵轴是音高，屏幕上画出来的线，就是你听到的声音。

A 303-style acid machine where every track is a function curve: time across, pitch up. The line on the screen is the sound you hear.

  • 16 步 303 式音序
  • 16 steps, the 303's way
  • 4 轨 ACID · BIO · KICK · PERC
  • 4 tracks: ACID · BIO · KICK · PERC
  • 8 条预设旋律
  • 8 preset lines
  • 4 层梯形滤波
  • 4-pole ladder
  • 录旋钮动作
  • knob motion
  • 按住 FX 的效果层
  • hold-FX punch-ins

01安装Install

  1. 先备份 SLOOP 的工程SLOOP 编辑器 → Projects → Backup。FN ACID 读不了 SLOOP 的工程；刷回 SLOOP 后可以恢复。
  2. Back up SLOOP firstSLOOP editor → Projects → Backup. FN ACID cannot read SLOOP's projects; restore them after going back.
  3. 用 USB 线直接插电脑要能传数据的线，不要经过 Hub 或转接器；FM-1 开机。关掉其它用 MIDI 的软件。
  4. Plug the FM-1 straight into the computerA data cable, no hub or adapter; switch it on. Close other apps that use MIDI.
  5. 用电脑上的 Chrome 或 Edge 打开本页要 Web MIDI。浏览器问 MIDI 权限时选“允许”。
  6. Open this page in Chrome or EdgeIt needs Web MIDI. Allow MIDI when the browser asks.
  7. 按下面的按钮，等它走完两三分钟。FM-1 会自己重启，屏幕变成荧光绿的 FN ACID。
  8. Press the button and let it finishTwo or three minutes. The FM-1 restarts by itself into the lime FN ACID screen.

写入时别切走这个标签页，也别最小化浏览器：后台标签页会被浏览器限速，每块数据之间的等待从 10 毫秒变成约 1 秒，整个过程会慢好几倍。也别拔线。Keep this tab in front while it writes and do not minimise the browser: a background tab is throttled (each block waits ~1 s instead of 10 ms), so it gets many times slower. Do not unplug.

  • 0.392026-10-24
    • 曲目模式：「Acid 的八种玩法」里的 6 首完整曲子装进了机器（芝加哥、极简、两台 303、尖叫、碎拍、大场面）。按住 HOME + 白键 1–6 选曲，从头放到尾：段落、两台 303、909、旋钮怎么拧、回声混响、静一拍再落下、上升噪声，都照网页原曲
    • 开机演示：开机直接放一首（放完接下一首）。按 PLAY = 停下，回到你自己的设置，什么都没丢。GLO 第 4 页 START 可以关掉演示，或指定开机放哪首
    • 放曲子时：OCT+ = 下一段，OCT− = 回到这段开头（刚开始时 = 上一段），SELECT 旋钮也能跳段；REC = 循环这一段；弹琴键 = 整首移调
    • 曲子自己在拧 CUTOFF / RESO / ENV / DECAY（屏幕上的数字跟着动）。你一拧，那个旋钮就归你，直到下一段曲子再接回去
    • 水下（要和弦垫）和拉格（要坦普拉）放在 0.40
    • Song mode: six of the "8 ways to play acid" songs, whole (CHICAGO, MINIMAL, TWO 303S, SCREAM, BREAKS, BIG ROOM). HOME held + white keys 1-6. Sections, both 303s, the 909, the knob moves, delay and reverb, the silent beat before a drop and the risers all follow the web originals
    • Boot demo: the FM-1 starts playing a song (then the next). PLAY = stop and get your own set back, untouched. GLO page 4 START turns it off or picks the song
    • In a song: OCT+ next section, OCT- this section's start (or the one before), SELECT walks sections too; REC loops the section; keys transpose the song
    • The song turns CUTOFF / RESO / ENV / DECAY itself (the numbers move). Turn one and it is yours until the next section
    • DEEP (pads) and RAGA (tanpura) come in 0.40

  • 0.382026-10-23
    • MIDI：NOTES OUT 打开时，ACID 的四个旋钮也发出去（ACID 的通道）：CUTOFF = CC 74、RESO = CC 71、ENV = CC 77、DECAY = CC 75。发的是正在听到的值（录了旋钮动作就跟着动作走），一变就发，每 2 秒全部再发一遍
    • 给「滤波隧道」网页用：拧机身上的旋钮，隧道的开口和墙上的光跟着变
    • MIDI: with NOTES OUT on, the four ACID knobs go out too (on the ACID channel): CUTOFF CC 74, RESO CC 71, ENV CC 77, DECAY CC 75. The value you hear (knob motion included), sent when it changes and all four again every 2 s
    • For the Filter Tunnel page: turn the knobs and the tunnel opens and glows
    • 
        
  • 0.372026-10-21
    • 修好停止后的底噪：镲（PERC）的包络在很小时停止衰减，噪声一直低低地响（播放时也垫在下面）；底鼓的“咔哒”和 909 的闪避也有同样的问题
    • 回声和混响的反馈回路改成向零取整：尾巴会真正衰减到 0，不再留下一点直流
    • Fixed the hiss after stop: the hat (PERC) envelope stalled once its decay step rounded to 0 (also under the music); the kick click and the 909 duck had the same flaw
    • The delay and reverb loops round toward zero: their tails end at 0, with no DC left
    • 
        
  • 0.362026-10-20
    • MIDI（USB）：按三下 GLO 进 MIDI 页。CLOCK：OUT = 发时钟和开始 / 停止，IN = 跟外部时钟走；NOTES OUT 打开后把音符发出去
    • 通道：ACID = ACID CH，BIO = 下一个通道，第 3 轨（909 用通用鼓号）和 PERC = 10 通道
    • USB-MIDI: GLO three times = MIDI. CLOCK OUT sends clock and start / stop, IN follows an external clock; NOTES OUT sends the notes
    • Channels: ACID on ACID CH, BIO on the next, track 3 (909 as GM drum notes) and PERC on 10
    • 
        
  • 0.352026-10-20
    • 909 鼓机（来自 X0X）：EDIT 选第 3 轨，KIT 选 909；再按 SEQ = 鼓的编辑页，11 个鼓一行一行排开
    • 鼓页：黑键选哪一行（并试听），白键是 16 步（点一下开，再点重音，再点关），KNOB1–4 = 这一行的音高 / 衰减 / 音量 / 另一项
    • 存档格改成 6 个（U1–U6）；0.33/0.34 的存档自动转过来（U7 舍去）
    • 909 drum machine (from X0X): EDIT on track 3, KIT = 909; then SEQ = the drum page, all 11 voices as rows
    • Drum page: black keys pick a row (and play it), white keys are the 16 steps (on, accent, off), KNOB1-4 = the row tune / decay / level / one more
    • Slots are now 6 (U1-U6); 0.33/0.34 saves are converted (U7 dropped)

SLOOP

        
打开 SLOOP 的安装页 按 Install，再用 SLOOP 编辑器把备份恢复。

        
Open SLOOP's installer, press Install, then restore your backup in the SLOOP editor.

Pick any FM-1 firmware (SLOOP, X0X, Felucca …) on thefirmwarehub.com.

      
USB 救援模式
USB rescue

        
开机就崩或黑屏：按住 OCT− 再开机，只剩升级通道，然后用本页或上面任何一个安装页重新刷。连续两次开机崩溃，它也会自己进救援模式。

        
Crashes at start or a black screen: hold OCT− while switching on (only the update path runs), then install again from any installer. Two crashed starts in a row enter it by themselves.

FN ACID is a firmware by Electro-Dig, after AA (@measure_plan), “trying to turn math into acid”. It is built on Dinghy (zvenson), which keeps the platform of Felucca (Leo Kuroshita @kurogedelic, Hügelton Instruments) and SLOOP (isod89): start-up, USB, the update path, the rescue. The installer code on this page is SLOOP 2.7.1's web installer (from Felucca), unchanged but for the package and the words it shows.
