离线原型

现在只在浏览器里出声，不连 FM-1。把这里写的线发到 FM-1、从 FM-1 读回来，需要以后的 FN ACID 固件加上编辑器协议（设计见 docs/editor-design.md）。试听是照固件的算法用 Web Audio 重写的，接近但不完全等于机器上的声音。

PRESETS 8 条预设旋律（连音色一起载入，和机器上 HOME + 白键 9–16 一样）

STEPS · 16点格子 = 写音 · 点同一个音 = 休止 · 拖动 = 一笔画过去

SOUND 音色（和机器上的旋钮同名、同范围）

FILE 导出 / 导入一条线

一条线 = 16 步 + 根音 / 长度 / 速度 + 音色，存成 JSON 文件，字段名就是固件 params_t 里的名字，以后可以原样发给 FM-1。浏览器也会记住你最后的状态（只在这台电脑上）。

FN ACID 编辑器原型 · GPL-3.0 · 预设和算法来自 firmware/src/dinghy.c（FN ACID 0.32）。试听照固件的 ACID 声部写成：按步的音高 / 连音 / 滑音（约 22 ms 的滑）、303 范围的 DECAY（200 ms–2 s）、重音、4 层梯形或 2 层 SVF、附点八分乒乓延时、小混响、4/4 底鼓和镲。没有做的：BIO 动物轨、公式模式、旋钮动作、FX 层。
