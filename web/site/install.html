FN ACID

函数 Acid · M-VAVE FM-1 的自制固件 · {{VER}} 测试版Function Acid · a custom firmware for the M-VAVE FM-1 · {{VER}} test

一台 303 式的 acid 机器，每条轨都是一条函数曲线：横轴是时间，纵轴是音高，屏幕上画出来的线，就是你听到的声音。

A 303-style acid machine where every track is a function curve: time across, pitch up. The line on the screen is the sound you hear.

  • 16 步 303 式音序
  • 16 steps, the 303's way
  • 4 轨 ACID · BIO · KICK · PERC
  • 4 tracks: ACID · BIO · KICK · PERC
  • 8 条预设旋律
  • 8 preset lines
  • 4 层梯形滤波
  • 4-pole ladder
  • 录旋钮动作
  • knob motion
  • 按住 FX 的效果层
  • hold-FX punch-ins

01安装Install

  1. 先备份 SLOOP 的工程SLOOP 编辑器 → Projects → Backup。FN ACID 读不了 SLOOP 的工程；刷回 SLOOP 后可以恢复。
  2. Back up SLOOP firstSLOOP editor → Projects → Backup. FN ACID cannot read SLOOP's projects; restore them after going back.
  3. 用 USB 线直接插电脑要能传数据的线，不要经过 Hub 或转接器；FM-1 开机。关掉其它用 MIDI 的软件。
  4. Plug the FM-1 straight into the computerA data cable, no hub or adapter; switch it on. Close other apps that use MIDI.
  5. 用电脑上的 Chrome 或 Edge 打开本页要 Web MIDI。浏览器问 MIDI 权限时选“允许”。
  6. Open this page in Chrome or EdgeIt needs Web MIDI. Allow MIDI when the browser asks.
  7. 按下面的按钮，等它走完两三分钟。FM-1 会自己重启，屏幕变成荧光绿的 FN ACID。
  8. Press the button and let it finishTwo or three minutes. The FM-1 restarts by itself into the lime FN ACID screen.

写入时别切走这个标签页，也别最小化浏览器：后台标签页会被浏览器限速，每块数据之间的等待从 10 毫秒变成约 1 秒，整个过程会慢好几倍。也别拔线。Keep this tab in front while it writes and do not minimise the browser: a background tab is throttled (each block waits ~1 s instead of 10 ms), so it gets many times slower. Do not unplug.

03想回去 / 刷坏了Going back / if it goes wrong

    

      
SLOOP

        
打开 SLOOP 的安装页 按 Install，再用 SLOOP 编辑器把备份恢复。

        
Open SLOOP's installer, press Install, then restore your backup in the SLOOP editor.

      
FM-1 Firmware Hub

        
在 thefirmwarehub.com 选任何一个 FM-1 固件（SLOOP、X0X、Felucca……）装回去。

        
Pick any FM-1 firmware (SLOOP, X0X, Felucca …) on thefirmwarehub.com.

      
USB 救援模式
USB rescue

        
开机就崩或黑屏：按住 OCT− 再开机，只剩升级通道，然后用本页或上面任何一个安装页重新刷。连续两次开机崩溃，它也会自己进救援模式。

        
Crashes at start or a black screen: hold OCT− while switching on (only the update path runs), then install again from any installer. Two crashed starts in a row enter it by themselves.

FN ACID is a firmware by Electro-Dig, after AA (@measure_plan), “trying to turn math into acid”. It is built on Dinghy (zvenson), which keeps the platform of Felucca (Leo Kuroshita @kurogedelic, Hügelton Instruments) and SLOOP (isod89): start-up, USB, the update path, the rescue. The installer code on this page is SLOOP 2.7.1's web installer (from Felucca), unchanged but for the package and the words it shows.
